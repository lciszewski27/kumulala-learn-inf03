JavaScript bez paniki

od kliknięcia przycisku do wyniku, który widzi komisja

Skrypt to osobny rezultat oceniania (R.5). Nie chodzi o całą znajomość języka — chodzi o kilka powtarzalnych kroków: pobierz dane, policz, sprawdź warunek, wyświetl wynik. Ta ściąga układa je w tej właśnie kolejności.

Jak czytać tę ściągę

✦ różowe ramki

Cytat z arkusza. Zwróć uwagę na czasownik: pobiera, oblicza, wyświetla, sprawdza. Każdy z nich ma niżej swój kod.

✦ ciemne bloki

Gotowy skrypt. Dopasuj id, nazwy pól i komunikaty. Nie zmieniaj kolejności: pobranie → obliczenie → wyświetlenie.

✓ okiem komisji

Kryteria R.5 (skrypt). Sprawdzają kod źródłowy i działanie strony — nie estetykę skryptu.

! pułapki

Najczęstsze miejsca, w których skrypt „prawie działa”. Przeczytaj przed oddaniem płyty.

tak pisze arkusz · 2025 styczeń

Gdzie wstawić skrypt

Trzy miejsca, jedna zasada: element musi istnieć, zanim go pobierzesz

Najczęstszy błąd na starcie to skrypt w <head>, który próbuje pobrać pole, którego jeszcze nie ma w dokumencie. Rozwiązanie: wstaw <script> przed </body> albo użyj defer.

Wariant A — na końcu body
<body>
  <!-- cała strona -->
  <script src="skrypt.js"></script>
</body>

Najprostszy i najbezpieczniejszy. Elementy są już wczytane.

Wariant B — w head z defer
<head>
  <script src="skrypt.js" defer></script>
</head>

defer czeka na wczytanie HTML. Bez tego getElementById zwróci null.

Skrypt w pliku czy w HTML?

SytuacjaRozwiązanie
arkusz wymaga pliku skrypt.js<script src="skrypt.js"></script> przed </body>
mały skrypt tylko na jednej stronie<script> ... </script> przed </body>
skrypt ma działać po wczytaniu stronywindow.onload = function() { ... } lub defer
przycisk ma uruchomić funkcjęonclick="nazwaFunkcji()" w HTML

Dwa sposoby podpięcia zdarzenia

onclick w HTML — najczęstszy zapis egzaminacyjny raty.html
<button type="button" onclick="oblicz()">Oblicz</button>
<p id="wynik"></p>

<script>
function oblicz() {
  // 1. pobierz dane
  // 2. oblicz
  // 3. wyświetl wynik
}
</script>
addEventListener — równoważny, akceptowany przez komisję skrypt.js
const przycisk = document.getElementById("oblicz");

przycisk.addEventListener("click", function () {
  const powierzchnia = parseFloat(
    document.getElementById("powierzchnia").value
  );
  const puszki = Math.ceil(powierzchnia / 4);
  document.getElementById("wynik").innerHTML =
    "Liczba potrzebnych puszek: " + puszki;
});
!

Nie używaj <form action="..."> bez potrzeby. Przycisk type="submit" przeładuje stronę i wynik zniknie. W zadaniach z JS użyj type="button" albo zatrzymaj formularz przez event.preventDefault().

✓

Okiem komisji (R.3): dla przycisku musi być zdefiniowane zdarzenie, które uruchamia funkcję skryptu — w HTML przez onclick lub w JS przez addEventListener. Sam przycisk bez zdarzenia nie daje punktu.

✦

Zasada: .value zawsze zwraca tekst. Jeśli robisz "5" + 1, dostaniesz "51", a nie 6. Dlatego każdą wartość liczbową przepuść przez parseInt lub parseFloat. Gdy konsola pokazuje Cannot read properties of null, getElementById nie znalazł elementu — sprawdź id i miejsce skryptu.

obliczenie z zaokrągleniem w górę — wzorzec 2023 skrypt.js
function policz() {
  // 1. pobierz wartość i zamień na liczbę
  const powierzchnia = parseFloat(
    document.getElementById("powierzchnia").value
  );

  // 2. jedna puszka = 1 litr, 1 litr = 4 m2
  const liczbaPuszek = Math.ceil(powierzchnia / 4);

  // 3. wyświetl dokładnie tak, jak chce arkusz
  document.getElementById("wynik").innerHTML =
    "Liczba potrzebnych puszek: " + liczbaPuszek;
}

Pętla po polach wyboru — suma zaznaczonych kursów

forEach + checked + suma skrypt.js
const pola = document.querySelectorAll('input[type="checkbox"]');
let suma = 0;

pola.forEach(function (pole) {
  if (pole.checked) {
    suma += Number(pole.value);   // value musi być liczbą
  }
});

document.getElementById("wynik").innerHTML =
  "Koszt całkowity: " + suma + " zł";
✦

Kiedy pętla, a kiedy dwa ify? Jeśli kursów są dwa i znasz ich ceny, dwa if są szybsze. Jeśli pól jest więcej albo ceny są w value, użyj pętli — kod nie zależy wtedy od liczby checkboxów.

Zamiana liczby na system binarny

toString(2) + padStart + indeks dolny skrypt.js
const liczba = parseInt(document.getElementById("liczba").value);
const binarna = liczba.toString(2);              // 26 → "11010"

// dopełnij zerami do pełnych bloków 4-bitowych
const dlugosc = Math.ceil(binarna.length / 4) * 4;
const padded = binarna.padStart(dlugosc, "0");   // "00011010"

// podziel na bloki po 4 znaki od lewej
const bloki = [];
for (let i = 0; i < padded.length; i += 4) {
  bloki.push(padded.slice(i, i + 4));
}
const wynik = bloki.join(" ");                   // "0001 1010"

document.getElementById("wynik").innerHTML =
  "<p>Postać binarna: " + wynik + "<sub>(2)</sub></p>";

.files, File.name i createObjectURL skrypt.js
function pokazPlik() {
  const input = document.getElementById("plik");
  const plik = input.files[0];            // pierwszy wybrany plik

  if (plik) {
    // wyświetl nazwę pliku
    document.getElementById("nazwa").textContent = plik.name;

    // stwórz podgląd obrazu
    const img = document.createElement("img");
    img.src = URL.createObjectURL(plik);  // blob URL do pliku
    img.alt = plik.name;
    img.style.maxWidth = "200px";

    const podglad = document.getElementById("podglad");
    podglad.appendChild(img);             // dodaj do strony
  }
}
✦

createElement + appendChild pozwalają tworzyć znaczniki w JavaScript bez składania stringów. createElement("img") tworzy obraz, appendChild(img) wstawia go w wybranym miejscu. URL.createObjectURL(plik) tworzy tymczasowy adres dla pliku z dysku.

!

Nie nadpisuj innerHTML w każdej iteracji. lista.innerHTML = ... wewnątrz pętli usuwa poprzednie elementy. Zbierz cały HTML do zmiennej (jak wyżej) i przypisz go raz po pętli.

✓

Okiem komisji: nazwy zmiennych i funkcji muszą być znaczące. let a = 1; let b = 2; może przejść składniowo, ale traci punkt za czytelność. Używaj powierzchnia, liczbaPuszek, obliczRate.

function przeslij() {
  const imie = document.getElementById("imie").value.toUpperCase();
  const nazwisko = document.getElementById("nazwisko").value.toUpperCase();
  const zgloszenie = document.getElementById("zgloszenie").value;
  const regulamin = document.getElementById("regulamin").checked;

  const wynik = document.getElementById("wynik");

  if (!regulamin) {
    wynik.innerHTML = "Musisz zapoznać się z regulaminem";
    wynik.style.color = "red";
  } else {
    wynik.innerHTML = imie + " " + nazwisko +
      "<br>Treść Twojej sprawy: " + zgloszenie;
    wynik.style.color = "Navy";
  }
}

JavaScript — suma kursów, rata, pełny komunikat skrypt.js
function oblicz() {
  const react = document.getElementById("kursReact").checked;
  const javascript = document.getElementById("kursJavaScript").checked;
  const liczbaRat = parseInt(
    document.getElementById("liczbaRat").value
  );
  const miasto = document.getElementById("miasto").value;

  let kwota = 0;
  if (react) kwota += 5000;
  if (javascript) kwota += 3000;

  const rata = kwota / liczbaRat;

  document.getElementById("wynik").innerHTML =
    "Kurs odbędzie się w " + miasto +
    ". Koszt całkowity: " + kwota +
    " zł. Płacisz " + liczbaRat +
    " rat po " + rata.toFixed(2) + " zł";
}
✓

Co sprawdza komisja: ceny React.js 5000 i JavaScript 3000, suma tylko zaznaczonych kursów, podział przez liczbę rat, miasto z listy oraz komunikat pod przyciskiem. Wystarczy sprawdzić dwa różne miasta i dwie różne liczby rat.

! Najczęstsze pułapki
  • value to tekst. Bez parseInt / parseFloat dodawanie skleja stringi.
  • Zły id. HTML ma id="wynik", JS szuka "Wynik" — wielkość liter ma znaczenie.
  • Skrypt przed elementem. getElementById zwraca null.
  • Przycisk submit. Strona się przeładowuje, wynik znika.
  • Brak checked. Sama obecność checkboxa nie znaczy, że jest zaznaczony.
  • Dzielenie przez 0 i NaN. Puste pole liczbowe → parseInt("") → NaN. Jeśli liczba rat to 0, wynik to Infinity. Zawsze sprawdź: if (liczbaRat > 0) { ... }.
  • Nadpisywanie innerHTML w pętli. Zostaje tylko ostatni element.
!

innerHTML vs textContent. innerHTML interpretuje HTML. Jeśli dane od użytkownika zawierają znaczniki, mogą zostać wykonane. Gdy wyświetlasz tylko tekst (np. imię użytkownika), użyj textContent: wynik.textContent = imie + " " + nazwisko;. innerHTML zachowaj do sytuacji, gdy świadomie generujesz HTML (np. lista z <li>).

✓

Minimum punktowe: zdarzenie na przycisku + pobranie choć jednej kontrolki + poprawna instrukcja + wynik pod przyciskiem. To już kilka punktów z rezultatu R.5.

Checklista JavaScript przed oddaniem

  • skrypt jest w JavaScript, nie w PHP
  • przycisk ma onclick lub addEventListener
  • każde getElementById ma istniejący id
  • wartości liczbowe są konwertowane
  • checkbox sprawdzany przez .checked
  • lista rozwijana przez .value
  • wynik trafia do paragrafu pod przyciskiem
  • komunikat ma dokładne słowa z arkusza
  • kolor komunikatu zmieniony, jeśli wymagany
  • wielkie litery przez toUpperCase()
  • zaokrąglenie w górę przez Math.ceil()
  • rata przez toFixed(2), jeśli trzeba
  • brak błędów w konsoli (F12)
  • skrypt działa po odświeżeniu strony
  • nazwy zmiennych są znaczące
  • skrypt nie przeładowuje strony
  • sprawdzone dwa miasta i dwie liczby rat
  • sprawdzone zaznaczenie obu kursów i żadnego
  • wynik widać także po resecie formularza
  • plik zapisany w folderze z numerem zdającego
